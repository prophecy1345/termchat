# termchat

English: [README.md](README.md).

Приватный мессенджер для терминала, только текст. Сквозное шифрование через
[vodozemac](https://github.com/matrix-org/vodozemac) (Olm: рукопожатие в стиле X3DH и
Double Ratchet, та же схема, что в Signal и Matrix). Tor по желанию. Никаких аккаунтов,
телефонов, email и имён: вы — это пара ключей и ник, который выбираете сами.
Сайт: [termchat.app](https://termchat.app/ru/).

**Статус: без аудита.** Криптография взята из vodozemac, который прошёл аудит в 2022
году; собственный код termchat внешней проверки не проходил. Считайте проект
экспериментальным.

termchat — бесплатный некоммерческий проект с открытым кодом, который создаётся и
поддерживается как личное хобби. В нём нет рекламы, подписок, платных функций и
монетизации. Любой может запустить свой relay-сервер.

## От чего защищает, а от чего нет

Цель не «невозможно взломать», а «взламывать сервер бессмысленно».

**Защищено**
- Содержимое сообщений — от провайдера, Wi-Fi, оператора relay и того, кто изымет
  сервер: на relay только шифртекст.
- Старые сообщения, если ключ утечёт позже (forward secrecy), и новые, когда
  атакующий потеряет доступ (post-compromise security).
- Подмена, повтор и перестановка сообщений; пропавшие сообщения обнаруживаются и
  показываются.
- Выдача себя за другого: один раз сверьте с собеседником номер безопасности (Ctrl+F).
- Ваш IP-адрес — от relay и провайдера, когда включён Tor.
- Данные на диске: всё зашифровано вашим паролем (Argon2id).

**Частично**
- **Метаданные.** Relay видит, какой ключ кому пишет и когда, и размер сообщения,
  округлённый до 512 / 4096 / 16384 байт. Ники ему не видны.
- **Человек у вашего разблокированного компьютера.** Автоблокировка через 5 минут,
  Ctrl+K — заблокировать сразу, исчезающие сообщения, чаты без истории.
- **Принуждение выдать пароль.** Пароль под принуждением молча стирает всё. Он не
  поможет, если диск скопировали заранее; код открыт; уничтожение данных после
  изъятия может быть преступлением там, где вы живёте.
- **Потеря устройства.** Только при наличии резервной копии (Ctrl+P, b).

**Не защищено**
- Вредоносное ПО, кейлоггер, скомпрометированный терминал или ОС.
- Глобальный наблюдатель, сопоставляющий время трафика (Tor от этого не спасает).
- Ключи в swap и файле гибернации: включите шифрование диска средствами ОС.
- На Windows: нет защиты от core dump и прав `0600` на файлы (только Unix); файл
  состояния всё равно зашифрован вашим паролем.

Подробно: [docs/threat-model.ru.md](docs/threat-model.ru.md).

## Установка

Скачайте архив для своей системы со страницы
[релизов](https://github.com/prophecy1345/termchat/releases). В каждом лежат `termchat`
(клиент) и `termchat-relay` (сервер). Самые быстрые способы (Homebrew, одна команда)
описаны в [руководстве](#1-установка).

### Проверка релиза

1. **Чексумма:** `sha256sum -c SHA256SUMS --ignore-missing` (macOS:
   `shasum -a 256 -c SHA256SUMS --ignore-missing`).
2. **Происхождение:** `gh attestation verify termchat-<версия>-<платформа>.tar.gz --repo prophecy1345/termchat`
   доказывает, что архив собран workflow этого репозитория из конкретного коммита
   (Sigstore, доверять ключам не нужно).
3. **Пересоберите сами:** сборки воспроизводимые.

   ```sh
   git clone https://github.com/prophecy1345/termchat && cd termchat
   git checkout v<версия>
   scripts/build-release.sh <платформа>     # для Linux musl: BUILD=zigbuild
   shasum -a 256 target/<платформа>/release/termchat target/<платформа>/release/termchat-relay
   ```

   Хеши должны совпасть с `BINARIES.sha256` внутри архива.
4. **Android APK:** шаги 1 и 2 подходят и для `.apk`. Сертификат подписи должен быть этим (`apksigner verify --print-certs <apk>` или сведения о приложении в Android): SHA-256
   `BC:6A:74:2E:73:CF:B7:55:CD:24:6B:C0:F2:73:DF:FF:71:8A:78:77:7D:4C:CB:41:9A:8D:D4:A6:4A:76:BA:5E`.

Зависимости проверяются через `cargo deny` (лицензии, известные уязвимости) и
`cargo vet` (импортированные аудиты Mozilla, Google и других; остальное перечислено
как ещё не проверенное в `supply-chain/`).

## Руководство пользователя

termchat работает в окне терминала. Можно пользоваться клавиатурой или мышью. Список
клавиш в любой момент открывается по **?** (или **F1**), меню — по **Ctrl+P**; там же
есть английская версия этого руководства.

Интерфейс программы на английском, поэтому надписи с экрана здесь приведены как есть.

### 1. Установка

Выберите один из способов.

**Homebrew** (macOS, Linux):
```sh
brew install prophecy1345/tap/termchat
```
Обновление: `brew update && brew upgrade termchat` (без `brew update` Homebrew может до суток не видеть новую версию).

**Одной командой** (macOS, Linux): скрипт скачает нужную сборку, проверит чексумму и положит `termchat` в `~/.local/bin`.
```sh
curl -fsSL https://raw.githubusercontent.com/prophecy1345/termchat/main/scripts/install.sh | sh
```

**Одной командой** (Windows, в PowerShell): установит в `%LOCALAPPDATA%\Programs\termchat` и добавит эту папку в PATH.
```powershell
irm https://raw.githubusercontent.com/prophecy1345/termchat/main/scripts/install.ps1 | iex
```

После этого откройте новый терминал и запустите `termchat`.

**Android** (8.0 и новее, сервисы Google не нужны): скачайте `termchat-<версия>-android-arm64.apk` со страницы [релизов](https://github.com/prophecy1345/termchat/releases) и откройте его; Android один раз спросит разрешение ставить приложения из браузера. О новой версии приложение скажет само, в списке чатов. Сборка в F-Droid готовится, с той же подписью, что и APK здесь.

**Вручную.** Скачайте архив для своего компьютера со страницы [релизов](https://github.com/prophecy1345/termchat/releases):

| Компьютер | Архив |
|---|---|
| Mac на Apple Silicon (M1 и новее) | `termchat-<версия>-aarch64-apple-darwin.tar.gz` |
| Mac на Intel | `termchat-<версия>-x86_64-apple-darwin.tar.gz` |
| Linux, обычный 64-битный ПК | `termchat-<версия>-x86_64-unknown-linux-musl.tar.gz` |
| Linux на ARM (Raspberry Pi 4/5, ARM-серверы) | `termchat-<версия>-aarch64-unknown-linux-musl.tar.gz` |
| Windows 10/11 | `termchat-<версия>-x86_64-pc-windows-msvc.zip` |

- **Windows:** откройте `.zip`, распакуйте, дважды щёлкните `termchat.exe` (лучше всего выглядит в Windows Terminal). SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
- **macOS:** `tar -xzf termchat-*-apple-darwin.tar.gz`, затем в этой папке `xattr -d com.apple.quarantine termchat` (программа не подписана Apple; без этого macOS напишет, что её «нельзя открыть, так как не удалось проверить разработчика») и `./termchat`. Двум способам выше этот шаг не нужен.
- **Linux:** `tar -xzf termchat-*-linux-musl.tar.gz`, затем `./termchat` в этой папке. Программа собрана статически, ставить библиотеки не нужно.

`termchat --version` покажет установленную версию. Перед первым запуском можно убедиться, что скачанный файл подлинный: см. раздел [Проверка релиза](#проверка-релиза).

### 2. Первый запуск

На экране настройки шесть полей. **Tab** или **Enter** переходят к следующему, **Shift+Tab** — к предыдущему.

| Поле | Что вводить |
|---|---|
| Relay URL | Уже заполнено адресом [публичного relay](#публичный-relay). Оставьте или впишите адрес другого relay. |
| Relay onion URL | Уже заполнено. Нужно только для Tor. |
| Use Tor? | `y` скрывает ваш IP-адрес от relay и интернет-провайдера; первое подключение занимает 10–30 секунд. `n` — напрямую, быстрее. |
| Nickname | Ник, который увидят ваши контакты. Это единственное, что о вас кто-то узнает; настоящее имя не нужно. До 64 байт. |
| Password | Шифрует всё, что лежит на диске. Должен быть стойким; **Ctrl+G** сгенерирует шесть случайных слов. Запишите его: восстановить пароль нельзя. |
| Repeat password | Тот же пароль ещё раз. |

Сразу после настройки termchat предложит сделать резервную копию (см. [раздел 8](#8-резервная-копия-и-восстановление)). Пока её нет, в строке состояния горит `! no backup: Ctrl+P`.

### 3. Экран

```
 contacts                 │ alice·36335   ! not verified (Ctrl+F)
                          │
 ! alice·36335            │ alice·36335  2m
 ● bob              2     │ hi!
 ? carol·58121            │
                          │ you  now
                          │ hello ✓
                          │
                          │ › здесь печатаете, Enter отправляет
 + add             ≡ menu │
 ● online  you  ! no backup: Ctrl+P         ^P menu  ? keys  ^K lock  ^Q quit
```

- **Слева** — контакты, сверху самые свежие чаты. Щёлкните по контакту или выберите его **стрелками вверх/вниз**. Число справа — непрочитанные сообщения. Границу между списком и чатом можно перетащить мышью. В узком окне список прячется, стрелки по-прежнему переключают чаты.
- **Справа** — переписка с выбранным контактом. Сообщения сгруппированы под именем отправителя и возрастом: `now` (только что), `2m` (2 минуты), `3h` (3 часа), `4d` (4 дня). **PgUp/PgDn** или колесо мыши листают историю; `↓ PgDn` значит, что вы не на последнем сообщении.
- **Внизу** — поле ввода. **Enter** отправляет. Длинный текст переносится. Редактирование: **←/→**, **Home/End**, **Alt+←/→** (по словам), **Ctrl+W** (стереть слово), **Ctrl+U** (стереть до начала).
- **Строка состояния:** `● online` (на связи), `● online via Tor` (на связи через Tor) или `○ connecting…` (подключается); ваш ник; предупреждения. Подсказки справа можно нажимать мышью.
- **Правый щелчок** по контакту открывает все действия с ним: принять, переименовать, сверить, исчезающие сообщения, заблокировать, пожаловаться, удалить.
- **Меню** (**Ctrl+P** или `≡ menu`): настройки, клавиши, руководство, ваше приглашение, добавить контакт, резервная копия.

Метки у контактов:

| Метка | Значение |
|---|---|
| `●` | Есть непрочитанные сообщения |
| `?` | Запрос контакта, который вы ещё не приняли |
| `!` | Номер безопасности ещё не сверен |
| `×` | Контакт заблокирован |
| `alice·36335` | Имя и начало отпечатка ключа. Показывается у непроверенных контактов и когда два имени совпадают. Ник выбирает сам человек, и отличить двух «alice» можно только по цифрам. |

Метки у ваших сообщений: `…` — отправляется, `✓` — принято relay, `✗` — не отправлено (причина рядом).

Пока мышь включена, обычное выделение текста терминалом работает с зажатым **Shift** (в некоторых терминалах macOS — **Option**). Мышь можно выключить в настройках.

### 4. Как добавить контакт

Поиска и каталога пользователей нет: люди добавляют друг друга, обмениваясь **приглашениями**.

1. **Ctrl+O** показывает ваше приглашение — длинную строку, начинающуюся с `termchat:`. Нажмите **c**, чтобы скопировать её (работает в iTerm2, kitty, WezTerm, Windows Terminal и других терминалах с поддержкой OSC 52; в стандартном Terminal на macOS не работает), или выделите мышкой. В приглашении только публичные ключи, поэтому его можно отправить по почте, через другой мессенджер или QR-кодом.
2. Ваш друг нажимает **Ctrl+A**, вставляет приглашение и нажимает **Enter**.
3. Теперь вы есть в списках друг у друга. У вас друг появится как **запрос** (`?`). **Ctrl+Y** — принять, **Ctrl+D**, затем **y** — отклонить.
4. Пока вы не приняли запрос, сообщения от этого человека скрыты: в заголовке чата видно, сколько их ждёт. Сохраняются первые 5, они появятся после принятия. Так незнакомец не может завалить ваш экран сообщениями.

Если вы оба добавили приглашения друг друга, запросом не будет никто.

### 5. Сверка номера безопасности (один раз для каждого контакта)

Relay не может читать сообщения. Но тот, кто контролирует сеть, может попытаться в момент добавления подсунуть вам свои ключи вместо ключей друга. Исключить это нужно один раз:

1. **Ctrl+F** показывает 60-значный номер безопасности. Друг открывает такой же экран у себя.
2. Сравните номера лично, по видеосвязи или по телефону (не через termchat).
3. Если совпали, нажмите **v**. Метка `!` и цифры после имени исчезнут.

Если номера разные, не доверяйте этому контакту: удалите его (**Ctrl+D**) и обменяйтесь приглашениями заново, другим способом.

### 6. Сообщения

- Напишите текст и нажмите **Enter**. Только текст, до 16 000 байт на сообщение (примерно 8 000 знаков кириллицей или 16 000 латиницей). Вставлять текст безопасно: вставленный текст никогда не срабатывает как нажатия клавиш.
- **Если друг не в сети,** relay хранит зашифрованное сообщение до 14 дней и доставит его, когда друг подключится.
- **«⚠ N message(s) missing»** значит, что какое-то сообщение для вас не дошло (потерялось или relay его выбросил). Если сообщение позже всё-таки придёт, предупреждение пропадёт.
- **«⚠ they restarted the conversation»** значит, что друг восстановился из резервной копии или переустановил программу. Сообщения, отправленные в этот момент, могли потеряться; больше ничего делать не нужно.

### 7. Действия с чатом

Всё ниже относится к выбранному контакту; тот же список открывается правым щелчком по нему.

| Клавиша | Что делает |
|---|---|
| **Ctrl+T** | Исчезающие сообщения: выкл → 5 минут → 1 час → 1 день → 1 неделя. Действует на то, что вы отправляете дальше; по истечении срока сообщение исчезает у обоих. В заголовке чата появится `⏱`. |
| **Ctrl+E** | Без истории: этот чат никогда не записывается на диск и пропадает, когда вы блокируете программу или выходите. |
| **Ctrl+R** | Переименовать контакт. Только у вас; пустое имя возвращает исходное. |
| **Ctrl+B** | Заблокировать или разблокировать. Сообщения заблокированного выбрасываются непрочитанными, писать ему нельзя. |
| **Ctrl+D** | Удалить контакт и переписку (спросит **y**). Удаление запроса — это окончательный отказ; если позже добавить приглашение этого человека, отказ снимается. |
| **Ctrl+X** | Пожаловаться оператору relay. Программа покажет, какие именно сообщения (последние 5 от этого человека) прочитает оператор; **y** отправляет жалобу и блокирует контакт. Ключ, на который пожаловались несколько разных людей, которым он действительно писал, блокируется на этом relay. |

### 8. Резервная копия и восстановление

Ваша личность (ключи) существует только на вашем устройстве. **Без резервной копии потеря или поломка устройства означает потерю личности,** и контактам придётся добавлять вас заново.

- **Сделать копию:** **Ctrl+P**, затем **b** (или настройки → security). Введите, куда сохранить (например, на флешку), и задайте пароль копии. В копии — ваша личность и список контактов, но не переписка. **Унесите копию с этого устройства** (флешка, другой компьютер).
- termchat помнит, куда записал копию или откуда её восстановил. Любое стирание, в том числе паролем под принуждением, удаляет копию, если она всё ещё лежит по этому пути: забытая на диске копия вас не выдаст. Перенесённую или скопированную в другое место копию программа не трогает: по ней вы вернёте личность.
- **Восстановить:** на экране первого запуска нового устройства нажмите **Ctrl+B**, укажите путь к копии и разблокируйте программу паролем копии. Переписка начнётся заново; контакты увидят «they restarted the conversation».
- Пользуйтесь **одним устройством за раз**: два устройства с одним ключом мешают друг другу.

**Переезд на другое устройство** (например, с Mac на ноутбук с Linux):

1. На старом устройстве сделайте **свежую** копию (**Ctrl+P**, **b**): в старой нет контактов, добавленных после неё.
2. Перенесите копию на новое устройство и закройте termchat на старом (**Ctrl+Q**).
3. Установите termchat на новое устройство. На экране первого запуска нажмите **Ctrl+B**, укажите путь к копии и разблокируйте программу паролем копии. Сменить его можно потом в настройках → security.
4. Проверьте, что контакты на месте, и напишите каждому. Их следующее сообщение начнёт новую переписку с этим устройством; отправленное во время переезда может потеряться.
5. На старом устройстве: настройки → security → wipe, и введите **`MOVED`**, а не `WIPE`. `MOVED` стирает только это устройство и никому ничего не сообщает. `WIPE` удалит аккаунт: контакты увидят, что вы ушли, и на новом устройстве тоже.
6. Удалите файл копии там, где он больше не нужен, или сохраните в надёжном месте как следующую копию.

### 9. Блокировка, пароли и стирание

- termchat **блокируется сам через 5 минут** без нажатий клавиш и щелчков; **Ctrl+K** блокирует сразу. Блокировка стирает ключи и сообщения из памяти; разблокировать можно паролем.

Остальное — в **настройках**: **Ctrl+P**, затем **s**, вкладка **security** (**Tab** или щелчок):

- **Сменить пароль:** текущий пароль, новый дважды.
- **Пароль под принуждением:** второй пароль. Если ввести его на экране разблокировки, программа молча сотрёт всё и покажет экран первого запуска, как будто termchat никогда не использовали. Сначала прочитайте предупреждение на этом экране: функция не поможет, если кто-то заранее скопировал ваш диск, а уничтожение данных после изъятия в некоторых странах считается преступлением. Чтобы выключить функцию, оставьте поле нового пароля пустым.
- **Стереть всё:** введите `WIPE`. Ключи, контакты и переписка будут стёрты с этого устройства. Отменить нельзя. Контакты получат прощание (чат с вами станет только для чтения), а relay забудет ваш ключ. Без связи клиент спросит, стирать ли, не предупредив их. Пароль под принуждением так не делает: он стирает молча. Переехали на другое устройство? Введите `MOVED`: это сотрёт только это устройство, молча (см. [переезд](#8-резервная-копия-и-восстановление)).
- **Включить или выключить Tor позже:** строка `Tor`.

### 10. Где хранятся данные

Всё лежит в одном зашифрованном файле `~/.termchat/state` (в Windows: `C:\Users\<вы>\.termchat\state`), плюс кеш Tor в `~/.termchat/arti`. Переменная `TERMCHAT_HOME` задаёт другой профиль, например чтобы попробовать termchat с двумя личностями на одном компьютере:

```sh
TERMCHAT_HOME=~/termchat-test ./termchat
```

### 11. Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Висит `○ connecting…` | Проверьте интернет. Через Tor первое подключение может занять до минуты. Если подключения нет совсем, выключите Tor в настройках (security) и посмотрите, доступен ли relay. |
| В строке состояния `SAVE FAILED` | Диск заполнен или недоступен для записи. Сообщения не подтверждаются relay, пока не сохранены, поэтому ничего не теряется; освободите место. |
| `wrong password` | Пароль чувствителен к регистру и раскладке клавиатуры. Восстановить его нельзя; если есть резервная копия, восстановитесь из неё. |
| `they use another relay` при добавлении контакта | Приглашение друга сделано для другого relay. Пока что вы оба должны пользоваться одним. |
| **c** не копирует приглашение | Ваш терминал не поддерживает доступ к буферу обмена (OSC 52). Выделите текст мышкой. |
| Интерфейс «поехал» | Увеличьте окно (хотя бы 80×24) и используйте шрифт с символами рамок Unicode. В старом терминале без 24-битного цвета выберите тему `terminal`. |
| Не выделяется текст мышью | Зажмите **Shift** при выделении или выключите мышь: настройки → interface. |
| Нет звука | В macOS играет системный звук; в Linux нужен `canberra-gtk-play` или `paplay`; иначе звенит терминал, а он может быть приглушён. |

### 12. Настройки, темы и уведомления

**Ctrl+P**, затем **s** открывает настройки. **Tab** или щелчок переключает вкладки, **стрелки** двигают выбор, **Enter** или щелчок меняет значение.

- **theme:** 18 цветовых тем, светлые и тёмные; при движении по списку тема сразу применяется. Чат остаётся на фоне вашего терминала, тема красит панели и окна.
- **notifications:** если пришло сообщение в чат, который вы сейчас не смотрите, в углу на 5 секунд появляется карточка с именем отправителя (без текста); щелчок открывает чат. **Sound** — системный звук уведомления (включён по умолчанию). **System notification** (по умолчанию выключено) просит терминал показать уведомление на рабочем столе, всегда с одним текстом «termchat: new message»: система хранит историю уведомлений вне termchat, поэтому имена и текст туда не попадают. В заголовке окна видно только число непрочитанных: `termchat (3)`.
- **interface:** мышь включена или выключена.
- **security:** резервная копия, пароль, пароль под принуждением, Tor, стирание.

Настройки лежат в `~/.termchat/settings.json` без шифрования, чтобы экран разблокировки был в вашей теме. О контактах там ничего нет, при стирании файл удаляется.

## Правила использования

termchat — для приватного общения. Он **не** предназначен для торговли людьми, оружием
или наркотиками, подготовки насилия или склонения к самоповреждению, и такое
использование запрещено. Мы не сканируем сообщения: со сквозным шифрованием это не
работает и было бы бэкдором для всех. Вместо этого termchat не даёт такой деятельности
охвата: нет поиска пользователей, каталога, публичных каналов и рассылок, незнакомцы
попадают в «запросы», любого можно заблокировать (Ctrl+B) и пожаловаться на него
оператору relay (Ctrl+X). См. [ADR-006](docs/adr/006-abuse-and-reports.ru.md).

**Что оператор relay может выдать:** публичные ключи, какой ключ кому и когда слал
конверты, недоставленный шифртекст (не старше 14 дней) и жалобы, которые пользователи
сами отправили. Не содержимое сообщений, не ники, не историю IP.

**Нужна помощь прямо сейчас?** На https://findahelpline.com есть телефоны доверия
любой страны.
