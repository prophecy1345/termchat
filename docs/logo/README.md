# termchat logo

A locked speech bubble containing a terminal prompt. The shackle, conversation tail and >_ prompt form a single compact mark.

Files
- termchat-mark-dark: 1024 × 1024; dark tile with 225 px corner radius.
- termchat-mark-transparent: same 1024 × 1024 mark with transparent surroundings.
- termchat-wordmark-dark / transparent: 1280 × 400 horizontal lockups.
- favicon-16.png / favicon-32.png: simplified, two-colour mark.
- favicon.svg: scalable simplified favicon.
- favicon.ico: 16 px and 32 px icon container.
- termchat-mono-mauve-on-dark / termchat-mono-dark-on-white: one-ink variants.
- termchat-preview: presentation overview.

All large assets are supplied as editable SVG and PNG. The wordmark uses Menlo Regular converted to vector paths; no font installation is required. Icon geometry uses consistent 64-unit rounded strokes. Small favicons use adjusted 1.5-unit strokes on a 16-unit grid. The terminal prompt is drawn geometry, not font text.

Palette
Background: #1e1e2e
Mauve: #cba6f7
Cursor: #94e2d5
Wordmark: #cdd6f4

The mark uses two foreground colours; the wordmark adds the specified light text colour. Favicon and monochrome variants use one foreground colour. No gradients, texture, glow or embedded raster content in the SVGs.

Keep at least one stroke width of space around the visible mark. Use the simplified favicon files at 16–32 px. The transparent light wordmark is intended for dark backgrounds.
