# ADR-033 — Приватные группы в CLI и daemon

English version — [ADR-033](033-scriptable-private-groups.md).

**Статус — реализовано.** Скриптовый режим ADR-024 и ADR-029 использует
членство, шифрование и доставку из ADR-027 и ADR-028. Управление группами
и приглашения остаются в приложении.

`groups` показывает группы, доступные этому устройству. `send` и `recv`
выбирают одну группу по точному отображаемому названию или полному ID.
CLI и daemon закрепляют ID на весь вызов и одинаково проверяют аргументы
и доступ. См. [руководство](../guide/scripts.ru.md#приватные-группы).

Движок проверяет доступ при постановке в очередь и перед передачей.
При известном переезде ожидающие кадры старой сессии отменяются, а новые
тексты ждут новой очереди и сессии Megolm. Успех означает подтверждение relay
для своего кадра. По истечении срока ожидания текст может остаться в очереди.

Новые входящие тексты получают отдельную отметку. Движок сохраняет выдачу
порции до передачи ожидающим читателям. Буфер каждого читателя вмещает
до 64 записей. При ошибке сохранения порцию можно забрать повторно. Сбой
после сохранения отметки может прервать вывод.
