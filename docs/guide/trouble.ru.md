# Если что-то не так

English version: [trouble.md](trouble.md).

| Проблема | Что делать |
|---|---|
| Висит на `○ connecting…` | Проверьте интернет. С Tor первое подключение может занять до минуты, через мосты — несколько минут. Если не подключается совсем, Tor может быть заблокирован там, где вы: добавьте [мосты](tor.ru.md). Или на минуту выключите Tor, чтобы проверить, доступен ли relay вообще. |
| `wrong password` | Пароль чувствителен к регистру и раскладке. Восстановить его нельзя; восстановите личность из копии, если она есть. |
| `SAVE FAILED` в строке состояния | Диск заполнен или недоступен для записи. Сообщения подтверждаются только после сохранения, поэтому ничего не потеряно; освободите место. |
| «termchat.app is already open in another window» (в скрипте: «this identity is open in another termchat») | Клиент для терминала, приложение для компьютера и команды для скриптов пользуются одной учётной записью по очереди. Закройте другую программу или дождитесь конца другой команды. |
| У контакта `↻` или «needs a new invite» | Он добавлен до версии 0.7.0. Обменяйтесь приглашениями заново. |
| «their app is older» | Ответам и реакциям нужна 0.9 у обоих; попросите обновиться. |
| **c** не копирует приглашение | Ваш терминал не даёт программам доступ к буферу обмена (OSC 52; Terminal на macOS не даёт). Выделите текст мышью с зажатым **Shift**. |
| Экран выглядит сломанным | Увеличьте окно хотя бы до 80×24 и выберите шрифт с символами рамок. В старом терминале без true color выберите тему `terminal`. |
| Не выделяется текст мышью | Держите **Shift**, пока тянете, или выключите мышь в настройках → interface. |
| Нет звука | macOS играет системный звук; в Linux нужен `canberra-gtk-play` или `paplay`; иначе звучит звонок терминала, который ваш терминал может глушить. |
| `termchat add` из скрипта завершился с кодом 4 | Запрос уйдёт со следующей командой; запустите любую, например `termchat contacts`. |

Что-то другое? Откройте issue на [github.com/prophecy1345/termchat/issues](https://github.com/prophecy1345/termchat/issues); вопрос или идею обсудите в [Discussions](https://github.com/prophecy1345/termchat/discussions). Оба места публичные: никогда не вставляйте туда пароль, копию или приглашение, а об уязвимости сообщайте приватно, как написано в [SECURITY.md](https://github.com/prophecy1345/termchat/blob/main/SECURITY.md).
