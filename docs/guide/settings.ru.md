# Настройки и данные

English version: [settings.md](settings.md).

## Как открыть настройки

- **Терминал:** **Ctrl+P**, затем **s**. **Tab** или щелчок переключают вкладки (theme, notifications, interface, security), **↑/↓** перемещают, **Enter** или щелчок меняют значение.
- **Компьютер:** **Settings** под списком контактов.
- **Android:** ⋮ → **Settings**.

Настройки безопасности (копия, пароли, Tor, мосты, подключения, время блокировки, стирание) описаны в разделах [Копии, блокировка, стирание](safety.ru.md) и [Tor и мосты](tor.ru.md).

## Темы

19 цветовых тем, светлые и тёмные, одинаковые во всех трёх приложениях; терминал добавляет `terminal` — его собственные 16 цветов для терминалов без true color. В терминале каждая тема видна сразу, пока вы листаете список; чат сохраняет фон терминала, а тема красит панели и окна.

## Уведомления

termchat.app никогда не кладёт имя или текст туда, где их хранит операционная система.

- **Терминал:** когда сообщение приходит в чат, который вы сейчас не смотрите, в углу на 5 секунд появляется карточка с именем отправителя (никогда не текстом); щелчок открывает чат. **sound for new messages** играет системный звук (macOS: Glass; Linux: `canberra-gtk-play` или `paplay`; иначе звонок терминала). **system notification** (выключено по умолчанию) просит терминал показать уведомление, которое всегда говорит только «termchat: new message». Заголовок окна показывает только число непрочитанных: `termchat (3)`.
- **Компьютер:** системный звук новых сообщений и, на macOS и Linux, системное уведомление, где написано только «New message», пока окно не на переднем плане; оба в **Appearance**. Linux нужен `notify-send` (пакет `libnotify-bin` или `libnotify`). На Windows уведомления пока нет.
- **Android:** см. [Android](android.ru.md): «termchat: New message», без имени и текста.

## Мышь (терминал)

Вкладка **interface** включает и выключает мышь. Пока она включена, обычное выделение текста в терминале работает с зажатым **Shift**.

## Где лежат данные

| | |
|---|---|
| `~/.termchat/state` | Всё о вашей личности: ключи, контакты, история. Один файл, зашифрованный вашим паролем. Windows: `C:\Users\<вы>\.termchat\state`. |
| `~/.termchat/arti` | Кэш каталога Tor, когда Tor включён. |
| `~/.termchat/settings.json` | Тема, звук, мышь, время блокировки. Не зашифрован, чтобы экран блокировки мог показать вашу тему; ничего о контактах в нём нет, и стирание удаляет его. |
| `~/.termchat/lock` | Не даёт второй программе открыть ту же учётную запись. |

Клиент для терминала и приложение для компьютера пользуются одной папкой. Задайте `TERMCHAT_HOME`, чтобы держать отдельную личность в другом месте, например попробовать termchat.app с двумя личностями на одном компьютере:

```sh
TERMCHAT_HOME=~/termchat-test termchat
```

На Android всё лежит в закрытом хранилище приложения.
