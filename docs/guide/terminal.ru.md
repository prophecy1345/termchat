# Терминал

English version: [terminal.md](terminal.md).

`termchat` работает в любом окне терминала. Пользуйтесь клавиатурой или мышью. **?** или **F1** в любой момент показывают список клавиш; **Ctrl+P** открывает меню, в нём же руководство.

## Экран

```
 contacts                  │ alice·36335   ! not verified (Ctrl+F)
                           │
 ! alice·36335             │ alice·36335  2m
 ● bob              2      │ hi!
 ? carol·58121             │
                           │ you  now
                           │ hello ✓
                           │
                           │ › message
 + add              ≡ menu │
 ● online  you  ! no backup: Ctrl+P          ^P menu  ? keys  ^K lock  ^Q quit
```

- **Слева:** контакты, последний чат сверху. Щёлкните по контакту или используйте **↑/↓**. Число справа — непрочитанные. Перетащите линию между списком и чатом, чтобы изменить ширину. В узком окне список прячется; **↑/↓** всё равно переключают чаты.
- **Справа:** чат. Сообщения сгруппированы под именем отправителя и возрастом (`now`, `2m`, `3h`, `4d`). **PgUp/PgDn** или колесо мыши листают назад; `↓ PgDn` значит, что вы не на последнем сообщении.
- **Внизу:** поле ввода. Длинный текст переносится.
- **Строка состояния:** `● online`, `● online via Tor` или `○ connecting…`, ваш ник и предупреждения. Подсказки справа кликабельны.

## Отметки

| Отметка | Значение |
|---|---|
| `●` | непрочитанные сообщения |
| `?` | запрос контакта, который вы ещё не приняли |
| `!` | номер безопасности ещё не сверен |
| `×` | заблокирован |
| `-` | контакт удалил свою учётную запись |
| `↻` | нужно новое приглашение (со времён до анонимных очередей) |
| `#` | группа; число справа — сколько в ней участников |
| `alice·36335` | имя и начало отпечатка: у непроверенных контактов и когда два имени похожи |
| `…` `✓` `✗` | ваше сообщение: отправляется, на relay, ошибка |
| `▲ ♥ ☺ ◎ ☹ ✧ ▼` | реакции: нравится, люблю, смешно, ого, грустно, спасибо, не нравится |

## Клавиши

| Клавиша | Действие |
|---|---|
| **Enter** | отправить |
| **↑ / ↓** | выбрать контакт |
| **PgUp / PgDn** | листать чат |
| **Shift+↑** или **Ctrl+N** | выбрать сообщение: **Enter** ответить, **e** исправить, **d** удалить у обоих, **1**–**7** реакция (повторно — убрать), **Esc** назад |
| **Ctrl+A** | добавить контакт по приглашению |
| **Ctrl+O** | ваше приглашение: **c** копировать, **p** публичное, **i** инкогнито, **r** отозвать неиспользованные |
| **Ctrl+Y** | принять запрос |
| **Ctrl+F** | номер безопасности: **v** отмечает проверенным |
| **Ctrl+S** | поиск в чате |
| **Ctrl+T** | исчезающие сообщения: выкл, 5m, 1h, 1d, 1w |
| **Ctrl+E** | без истории: чат только в памяти |
| **Ctrl+L** / **Ctrl+G** | отправить файл / сохранить последний полученный |
| **Ctrl+R** | переименовать контакт |
| **Ctrl+B** | заблокировать / разблокировать |
| **Ctrl+D** | удалить контакт или отклонить запрос |
| **Ctrl+X** | пожаловаться оператору relay |
| **Ctrl+P** | меню: **s** настройки, **k** клавиши, **m** руководство, **n** что нового, **o** приглашение, **a** добавить, **b** резервная копия, **g** новая группа, **v** устройства, **l** привязать к основному (новое устройство) |
| **Ctrl+K** | заблокировать сейчас |
| **Ctrl+Q** или **Ctrl+C** | выйти |
| **?** или **F1** | список клавиш |
| **Esc** | закрыть окно, отменить ответ или правку |

Правка набранного: **←/→**, **Home/End**, **Alt+←/→** (по словам), **Ctrl+W** (удалить слово), **Ctrl+U** (удалить до начала).

## Группы

Маленькая приватная группа до 32 устройств (32 человека с одним устройством; меньше, если у участников их несколько), только по приглашению.

- **Новая группа:** **Ctrl+P**, затем **g** и название. Вы её администратор.
- **Пригласить:** в группе **Ctrl+R** открывает участников, **a** — список контактов, которых можно пригласить. Только ваши контакты, с версией, которая знает группы.
- **Вступить:** приглашение приходит в чат с администратором; **Ctrl+Y** там — вступить.
- **В группе:** ответы, правка, удаление и реакции — как в чате. У имени каждого участника свой цвет, одинаковый на всех устройствах. Таймер (**Ctrl+T**) ставит только администратор.
- **Документы:** **Ctrl+L** отправляет (до 1 МиБ, по одному), **Ctrl+G** сохраняет последний полученный, как в чате.
- **Исключить:** **Ctrl+R**, выбрать участника, **x**. Группа переезжает в новую очередь; исключённый больше ничего не прочитает.
- **Выйти:** **Ctrl+D**. Остальным сообщат; чат остаётся у вас, только для чтения.

Новый участник не видит, что говорили до него.

## Мышь

Щелчок по контакту открывает его; правый клик — всё, что с ним можно сделать. Край списка контактов можно перетаскивать. Пока мышь включена, обычное выделение текста в терминале работает с зажатым **Shift** (в некоторых терминалах macOS — Option); или выключите мышь в настройках.
